# BAMITO - Badminton E-commerce Frontend

## Project Purpose
BAMITO is a modern, feature-rich e-commerce platform dedicated to badminton enthusiasts. This frontend application serves as the client interface for the BAMITO Backend API, providing a complete shopping experience for badminton equipment and accessories.

## Key Features & Capabilities

### Core E-commerce Functionality
- **Product Management**: Browse, search, and filter badminton products with advanced filtering options
- **User Authentication**: Complete registration, login, and session management system
- **Shopping Cart**: Persistent cart state with add/remove/update functionality
- **Order Management**: Full order processing, tracking, and history
- **User Profiles**: Personal account management with order history and delivery addresses
- **Product Reviews**: Customer feedback and rating system for products
- **Favorites System**: Save and manage favorite products
- **Voucher System**: Discount codes and promotional offers

### Admin Features
- **Product Administration**: Add, edit, delete, and manage product inventory
- **Order Management**: Process and track customer orders
- **User Management**: Admin controls for user accounts and permissions
- **Analytics Dashboard**: Sales charts and business metrics visualization
- **Content Management**: Manage product categories, brands, and site content

### Technical Capabilities
- **SEO Optimized**: Server-side rendering with dynamic metadata and JSON-LD structured data
- **Responsive Design**: Mobile-first design that works across all devices
- **Performance Optimized**: Next.js App Router for optimal loading and navigation
- **Type Safety**: Full TypeScript implementation for robust code quality
- **State Management**: Centralized Redux Toolkit for predictable state handling

## Target Users

### Primary Users
- **Badminton Players**: Enthusiasts looking for quality equipment and gear
- **Sports Retailers**: Businesses seeking badminton products for resale
- **Coaches & Clubs**: Organizations purchasing equipment in bulk

### Secondary Users
- **Site Administrators**: Managing products, orders, and site content
- **Customer Service**: Handling customer inquiries and order issues

## Use Cases

### Customer Journey
1. **Discovery**: Browse products by category, brand, or search terms
2. **Research**: Read reviews, compare products, check specifications
3. **Purchase**: Add to cart, apply vouchers, complete checkout with PayPal
4. **Account**: Manage profile, track orders, save favorites
5. **Engagement**: Leave reviews, contact support via chat integration

### Admin Operations
1. **Inventory Management**: Add new products, update stock levels, manage categories
2. **Order Processing**: Review orders, update status, handle customer requests
3. **Analytics**: Monitor sales performance, track popular products
4. **Content Management**: Update site information, manage promotional content

- **Performance**: Fast loading times and smooth navigation

- **Convenience**: Mobile-responsive design for shopping anywhere, anytime
